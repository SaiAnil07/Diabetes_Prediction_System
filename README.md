# 🩺 GlucoGuide – Diabetes Prediction System Using Machine Learning

### A Machine Learning-Based Diabetes Screening Web Application

GlucoGuide is an end-to-end Machine Learning web application designed to predict the likelihood of diabetes based on patient health measurements. It uses a **Random Forest Classifier** to analyze clinical and physiological parameters and classify individuals into diabetic and non-diabetic categories.

The application provides a simple, user-friendly interface where users can enter their health information and receive an instant ML-based screening result.

---

## 🌟 Project Overview

Diabetes is a chronic health condition that requires early detection and proper management. GlucoGuide aims to demonstrate how Machine Learning can support preliminary diabetes screening by analyzing important health parameters.

The system accepts patient information through a Flask web interface, processes the input using saved preprocessing components, and generates predictions using a trained Random Forest model.

### 🎯 Objectives

- Develop a machine-learning-based diabetes prediction system.
- Analyze patient health measurements.
- Apply data preprocessing and feature scaling.
- Train a Random Forest Classification model.
- Provide real-time predictions through a web interface.
- Display prediction results and model confidence.
- Demonstrate the practical application of Machine Learning in healthcare.

---

## 🚀 Key Features

## 📊 Input Features

The application uses the following eight features:

| Feature | Description |
|---|---|
| Age | Patient's age in years |
| Pregnancies | Number of pregnancies |
| Glucose | Blood glucose concentration |
| Blood Pressure | Diastolic blood pressure |
| Skin Thickness | Triceps skinfold thickness |
| Insulin | Insulin level |
| BMI | Body Mass Index |
| Diabetes Pedigree Function | Family-history-related diabetes risk indicator |

### 🎯 Prediction Classes

The model produces two classification outputs:

- **0 – Non-Diabetic**
- **1 – Diabetic**

---

## ⚙️ System Architecture

The application follows a simple machine learning pipeline:

1. **User Input:** Users enter their health measurements.
2. **Flask Application:** Receives patient information.
3. **Input Validation:** Checks the submitted values.
4. **Feature Ordering:** Arranges inputs according to the training feature order.
5. **Preprocessing:** Applies the saved StandardScaler.
6. **Prediction:** Random Forest Classifier generates the prediction.
7. **Result Display:** Displays the classification and predicted class probability.

## 💻 Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/GlucoGuide.git
```

### Step 2: Navigate to the Project Directory

```bash
cd GlucoGuide
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### Step 4: Install Dependencies

```bash
pip install flask numpy pandas scikit-learn joblib matplotlib seaborn
```

Alternatively:

```bash
pip install -r requirements.txt
```

### Step 5: Train the Machine Learning Model

If model artifacts are not already available, execute:

```bash
python train_model.py
```

This generates the required model files:

- model.pkl
- scaler.pkl
- class_encoder.pkl
- feature_names.pkl

### Step 6: Run the Flask Application

```bash
python app.py
```

### Step 7: Open in Browser

Visit:

```text
http://127.0.0.1:5000/
```

The GlucoGuide application is now ready to use.
